# Student OOP Assignment

A Python script that practices object-oriented programming (OOP) with a `Student` class, along with lists, tuples, sets and dictionaries.

## What it does

- **Part 1:** Defines a `Student` class with a name, email and list of grades, plus methods to add a grade, calculate the average and display info.
- **Part 2:** Creates 3 students, adds 2 grades to each, and prints their info and average grade.
- **Part 3:** Maps each email to its student in a dictionary, looks students up safely with `.get()`, and collects all unique grades in a set.
- **Part 4:** Returns grades as a tuple and shows that tuples can't be changed (caught with try/except).
- **Part 5:** Removes each student's last grade with `.pop()`, then prints their first grade, last grade and number of grades.

## How to run

1. Install [Python 3](https://www.python.org/downloads/).
2. Download or clone this repository.
3. In a terminal, open the project folder and run:

   python main.py

   (On a Mac, use `python3 main.py` if `python` doesn't work.)
